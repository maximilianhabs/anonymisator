# Verhaltenskodex

Kurz und pragmatisch, wie der Rest dieses Projekts.

## Der eine Grundsatz

Sachlich, respektvoll, konstruktiv — in Issues, Pull Requests und jeder
anderen Interaktion rund um dieses Projekt. Kein persönlicher Angriff,
keine Diskriminierung, keine Belästigung.

## Speziell für dieses Projekt

Dieses Werkzeug verarbeitet sensible medizinische Dokumente. Deshalb
zusätzlich, und das gilt strenger als in den meisten anderen Projekten:
**niemals ein echtes Dokument, einen echten Namen oder eine echte
Textstelle mit Personenbezug** in einem Issue, einem Pull Request oder
einer sonstigen Interaktion teilen — auch nicht in guter Absicht, auch
nicht zur Veranschaulichung eines Fehlers. Ein frei erfundenes Beispiel
zeigt jeden bisher bekannten Fehler genauso gut. Details dazu in
[CONTRIBUTING.md](CONTRIBUTING.md).

## Durchsetzung

Verstösse können über das GitHub-Profil
[@maximilianhabs](https://github.com/maximilianhabs) gemeldet werden.
Je nach Schwere: Hinweis, Bearbeitung oder Löschung des Beitrags,
Ausschluss von weiterer Mitwirkung. Dies ist ein einzeln betreutes
Projekt ohne eigenes Moderationsteam — eine feste Reaktionszeit kann
nicht zugesagt werden, eine Rückmeldung aber schon.

## Geltungsbereich

Gilt für alle Bereiche dieses Repositories (Issues, Pull Requests,
Diskussionen) sowie für jede Kommunikation im Namen des Projekts.
